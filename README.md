# 🎢 Playground Repository

Just a playground repository for learning purposes, experimenting with new tech stacks, and quick prototyping.

## 🚀 Tech Stack & Tools
- **Languages:** Python, JavaScript, HTML/CSS
- **Environments:** Jupyter Notebook, Node.js

## 📂 Repository Contents
Berikut adalah beberapa hal yang dieksperimenkan di repositori ini:
- `/data-analysis` : Skrip pemrosesan data, statistika harian, atau eksplorasi dataset.
- `/ui-ux-sandbox` : Prototipe visual, komponen layout web, atau eksperimen antarmuka digital.
- `/mini-scripts` : Alat otomatisasi kecil atau potongan kode logika (utility functions).
